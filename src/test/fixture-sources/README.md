# Synthetic Javadoc fixtures

The sources in `fixture/api` are test inputs, not part of the jDoc application.
Regenerate the committed HTML pages with JDKs 17, 21, and 25 installed:

```sh
for release in 17 21 25; do
  home=$(/usr/libexec/java_home -v "$release")
  "$home/bin/javadoc" -quiet -Xdoclint:none -notimestamp -noindex -notree \
    -nohelp -nodeprecatedlist -package -encoding UTF-8 \
    -d "src/test/resources/fixtures/$release" \
    src/test/fixture-sources/fixture/api/*.java
done
```

Only `Text`, `Sequence`, `Failure`, `Unit`, and `Dictionary` pages are tracked.
They characterize the HTML generated by each JDK without redistributing Oracle
API pages. The synthetic sources intentionally use analogous, not identical,
names to real JDK types.

For an opt-in check against the five official pages on each supported release,
run `JDOC_LIVE_TEST=true mvn -Dtest=JavadocLiveTest test`. The downloaded pages
are parsed in memory and are not checked into the repository.
